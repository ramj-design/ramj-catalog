# LUMINA — Lighting & Chandelier Catalog

A modern minimalist product catalog designed for GitHub Pages.

## Files

- `index.html` — website structure
- `style.css` — design and responsive layout
- `products.js` — product names, prices, descriptions, specifications, and image paths
- `script.js` — filters and product details modal

## Add your product photos

1. Create an `images` folder.
2. Put your product photos inside it.
3. Open `products.js`.
4. Change `image: ""` to something like:
   `image: "images/aurelia-ring.jpg"`

## Change prices and product details

All product information is in `products.js`.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload all files in this folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide your website URL.

For a custom domain, use the Pages settings after the site is published.
